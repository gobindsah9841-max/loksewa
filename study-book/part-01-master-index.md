## 1.4 Fixed layout used in every chapter

**Each topic has ten parts**

1. Why it matters — syllabus link and priority
2. Simple explanation
3. Key facts
4. Table
5. Numbers and dates to remember
6. Memory aid
7. Exam traps
8. Province link
9. Practice MCQs — each one labelled, with the answer and an explanation
10. Short-answer question with a model answer

**Each chapter ends with**

- Quick Revision
- Top 20 facts
- Top 25 MCQs (none repeated from the topics)
- Five short-answer questions
- Common mistakes
- Status of the facts (what was checked, and how)
- References

## 1.5 Marks used in the book

| Mark | Meaning |
|---|---|
| `[PYQ – Verified]` | A question traced to an official past paper. **Not used so far** — no official past paper could be verified. |
| `[Pattern-Based – Reconstructed]` | A question written to an official format (Level II types, syllabus model questions). It is **not** a real past question. |
| `[Expected – Practice]` | An original practice question on a point that the official syllabus names. |
| 🔄 **UPDATE** | A fact that changes with time. Check it again before the examination. |
| ⚖️ **DISPUTED** | A fact on which published sources disagree. Both versions are given. |

## 1.6 Commands

| You type | What happens |
|---|---|
| **CONTINUE** | The next pending Part is written, starting exactly where the progress tracker in `README.md` stops. |
| **UPDATE** | Every fact marked 🔄 in the written Parts is re-checked against current sources and corrected. |
| **MOCK TEST** | A full 50-question test is produced in the official format of the province you name, with an answer key and explanations. |
